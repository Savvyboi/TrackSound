# Test data

`trace_full_a2f38b.json` is a single aircraft trace (readsb `trace_full` format, gzip
compressed). It comes from the adsb.lol `globe_history` archive and was copied from
[dopplertrack](https://github.com/mjshiggins/dopplertrack)'s test fixtures.
