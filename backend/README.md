# TrackSound

A local web app for acoustic geolocation: work out where and when an audio or video
recording was made from faint sounds in it (propeller-aircraft Doppler curves vs ADS-B flight
history, thunder vs lightning catalogues, mains hum vs grid-frequency records, US emergency-alert
bursts), matched against public records of events at known places and times.

Install and run:

```bash
uv tool install tracksound      # or: pip install tracksound
tracksound                      # starts the app and opens it in your browser
```

Everything runs on your computer. See https://github.com/Savvyboi/TrackSound for the
downloadable apps, documentation and source.
